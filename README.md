# Systemy Rozproszone - prezentacja 1

## Struktura repozytorium
- code - kod w go
- presentation - prezentacja w latexu
- report - raport w latechu

## Uruchomienie kodu
Aby uruchomić kod należy użyć
```
go run prog.go
```
Następnie należy podać parametry. Można dodatkowo użyć flagi `-verbose` aby wypisać więcej informacji
